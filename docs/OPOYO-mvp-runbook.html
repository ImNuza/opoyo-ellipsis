Build a system that detects a hard fall from floor vibration, confirms the person did not get up, and escalates to a human — with no camera and nothing worn.

This document is written so you can work without asking anyone. That only holds if you follow the protocol exactly.

Every step has four blocks

Stop condition

If a VERIFY block has failed twice and 20 minutes have passed, stop working on it. Post to the team chat, in this order:

1. The step ID (e.g. P2.3)   2. The exact command you ran   3. The full output, not a summary   4. What you already tried.

Then start the next step that does not depend on this one. Do not sit blocked, and do not silently redesign around the problem — a changed contract breaks someone else's work.

from dataclasses import dataclass, asdict
from typing import Optional
import json, time, uuid

STATES = ("candidate", "vetoed", "recovered", "alert", "cancelled")

@dataclass
class FallEvent:
    event_id: str
    ts_unix: float
    room: str
    state: str              # one of STATES
    fall_score: float       # 0..1 from the classifier
    veto_label: Optional[str]   # e.g. "Television" or None
    veto_score: float           # 0..1
    peak_mag: float             # m/s^2 above gravity
    decay_ms: float             # peak -> 10% of peak

    @staticmethod
    def new(room: str, **kw) -> "FallEvent":
        return FallEvent(
            event_id=uuid.uuid4().hex[:12],
            ts_unix=time.time(),
            room=room,
            state=kw.pop("state", "candidate"),
            fall_score=kw.pop("fall_score", 0.0),
            veto_label=kw.pop("veto_label", None),
            veto_score=kw.pop("veto_score", 0.0),
            peak_mag=kw.pop("peak_mag", 0.0),
            decay_ms=kw.pop("decay_ms", 0.0),
        )

    def to_json(self) -> str:
        return json.dumps(asdict(self), separators=(",", ":"))

P1.2

Ring buffer

30 min
Goal

A fixed-memory rolling window of the last 30 seconds, so we can look backwards when something happens.

Do
opoyo/ring.py
import numpy as np
import threading

class RingBuffer:
    """Fixed-size circular float buffer. Thread-safe for one writer, many readers."""

    def __init__(self, capacity: int):
        self.capacity = int(capacity)
        self._buf = np.zeros(self.capacity, dtype=np.float32)
        self._n = 0                      # total samples ever written
        self._lock = threading.Lock()

    def push(self, samples) -> None:
        s = np.asarray(samples, dtype=np.float32).ravel()
        if s.size == 0:
            return
        if s.size >= self.capacity:
            s = s[-self.capacity:]
        with self._lock:
            start = self._n % self.capacity
            end = start + s.size
            if end <= self.capacity:
                self._buf[start:end] = s
            else:
                cut = self.capacity - start
                self._buf[start:] = s[:cut]
                self._buf[:end - self.capacity] = s[cut:]
            self._n += s.size

    def last(self, k: int) -> np.ndarray:
        """Most recent k samples, oldest first. Zero-padded if not yet filled."""
        k = min(int(k), self.capacity)
        with self._lock:
            if self._n == 0:
                return np.zeros(k, dtype=np.float32)
            end = self._n % self.capacity
            out = np.concatenate([self._buf[end:], self._buf[:end]])
            return out[-k:].copy()

    @property
    def total(self) -> int:
        return self._n

P2.1

Magnitude, high-pass, rolling RMS

40 min
Goal

Turn three noisy axes into one clean energy trace with gravity removed.

Do
opoyo/dsp.py
import numpy as np
from scipy.signal import butter, sosfilt, sosfilt_zi

def magnitude(x, y, z) -> np.ndarray:
    """Vector magnitude. Gravity is still in here; the high-pass removes it."""
    return np.sqrt(np.asarray(x)**2 + np.asarray(y)**2 + np.asarray(z)**2)

def make_highpass(cutoff_hz: float, fs: float, order: int = 2):
    """2nd-order Butterworth high-pass as second-order sections (numerically stable)."""
    return butter(order, cutoff_hz / (fs / 2.0), btype="highpass", output="sos")

class StreamingFilter:
    """Stateful filter so chunk boundaries don't create fake transients."""
    def __init__(self, sos):
        self.sos = sos
        self.zi = None

    def __call__(self, chunk) -> np.ndarray:
        c = np.asarray(chunk, dtype=np.float64)
        if c.size == 0:
            return c.astype(np.float32)
        if self.zi is None:
            self.zi = sosfilt_zi(self.sos) * c[0]
        out, self.zi = sosfilt(self.sos, c, zi=self.zi)
        return out.astype(np.float32)

def rolling_rms(sig, win: int) -> np.ndarray:
    """RMS over a sliding window, same length as input."""
    s = np.asarray(sig, dtype=np.float64)
    if win <= 1 or s.size == 0:
        return np.abs(s).astype(np.float32)
    p = np.pad(s**2, (win - 1, 0), mode="edge")
    c = np.cumsum(p)
    out = (c[win - 1:] - np.concatenate([[0.0], c[:-win]])) / win
    return np.sqrt(np.maximum(out, 0.0)).astype(np.float32)

def mad(v) -> float:
    """Median absolute deviation, scaled to be comparable to a standard deviation."""
    a = np.asarray(v, dtype=np.float64)
    m = np.median(a)
    return float(1.4826 * np.median(np.abs(a - m)))

def test_highpass_removes_gravity():

P2.2

Adaptive trigger

45 min
Goal

Fire when energy exceeds the room's own recent noise floor — not a fixed number, so it works in a quiet flat and a loud venue.

Do
opoyo/dsp.py — append
from dataclasses import dataclass

@dataclass
class Trigger:
    fs: float
    rms_window_ms: float = 100.0
    baseline_seconds: float = 10.0
    k_mad: float = 6.0
    refractory_s: float = 2.0
    min_peak_mag: float = 3.0

    def __post_init__(self):
        self._win = max(1, int(self.fs * self.rms_window_ms / 1000.0))
        self._hist = []                     # recent RMS values for the baseline
        self._hist_max = int(self.fs * self.baseline_seconds / self._win) + 1
        self._cooldown = 0.0                # seconds remaining

    def threshold(self) -> float:
        if len(self._hist) < 5:
            return float("inf")             # refuse to fire until the room is learned
        h = np.asarray(self._hist)
        return float(np.median(h) + self.k_mad * max(mad(h), 1e-3))

    def process(self, chunk) -> tuple[bool, float]:
        """Feed a chunk of high-passed magnitude. Returns (fired, peak_rms)."""
        r = rolling_rms(chunk, self._win)
        peak = float(r.max()) if r.size else 0.0
        dt = (len(chunk) / self.fs) if self.fs else 0.0

        thr = self.threshold()
        fired = (
            self._cooldown <= 0.0
            and peak > thr
            and peak > self.min_peak_mag
        )

        if fired:
            self._cooldown = self.refractory_s
        else:
            self._cooldown = max(0.0, self._cooldown - dt)
            # only quiet audio updates the baseline, so a fall can't raise its own threshold
            if peak < thr or thr == float("inf"):
                self._hist.append(peak)
                if len(self._hist) > self._hist_max:
                    self._hist.pop(0)
        return fired, peak
The subtle bit

The baseline updates only on quiet chunks. If you let loud chunks in, a fall raises the threshold that is supposed to catch it, and repeated events get progressively harder to detect. This is the single most common bug in adaptive-threshold detectors.

opoyo/features.py
import numpy as np

FEATURE_NAMES = ["peak", "rms", "crest", "rise_ms",
                 "decay_ms", "low_ratio", "centroid_hz"]

def extract(window: np.ndarray, fs: float) -> dict[str, float]:
    """window: high-passed acceleration magnitude, ~2 s. Never raises."""
    w = np.asarray(window, dtype=np.float64)
    if w.size < 8:
        return {k: 0.0 for k in FEATURE_NAMES}

    env = np.abs(w)
    peak = float(env.max())
    rms = float(np.sqrt((w**2).mean()))
    pk_i = int(env.argmax())
    crest = peak / rms if rms > 1e-9 else 0.0

    # rise: 10% of peak up to the peak
    thr = 0.1 * peak
    pre = np.nonzero(env[:pk_i + 1] >= thr)[0]
    rise_ms = ((pk_i - pre[0]) / fs * 1000.0) if pre.size else 0.0

    # decay: peak down to 10% of peak — the key discriminator
    post = np.nonzero(env[pk_i:] <= thr)[0]
    decay_ms = (post[0] / fs * 1000.0) if post.size else (env.size - pk_i) / fs * 1000.0

    # spectrum
    spec = np.abs(np.fft.rfft(w * np.hanning(w.size)))
    freqs = np.fft.rfftfreq(w.size, d=1.0 / fs)
    total = float(spec.sum()) + 1e-12
    low_ratio = float(spec[freqs <= 20.0].sum() / total)
    centroid_hz = float((freqs * spec).sum() / total)

    return {"peak": peak, "rms": rms, "crest": crest, "rise_ms": rise_ms,
            "decay_ms": decay_ms, "low_ratio": low_ratio, "centroid_hz": centroid_hz}

def to_vector(feats: dict[str, float]) -> np.ndarray:
    return np.array([feats[k] for k in FEATURE_NAMES], dtype=np.float64)

from typing import Protocol
import numpy as np
from opoyo.features import to_vector

class Classifier(Protocol):
    def score(self, feats: dict[str, float]) -> float: ...

class RuleClassifier:
    """Transparent baseline. Long decay + low-frequency energy = body-like."""
    def __init__(self, decay_ref_ms=180.0, low_ref=0.45, crest_ref=6.0):
        self.decay_ref_ms, self.low_ref, self.crest_ref = decay_ref_ms, low_ref, crest_ref

    @staticmethod
    def _sig(x):
        return 1.0 / (1.0 + np.exp(-x))

    def score(self, feats):
        d = feats.get("decay_ms", 0.0) / self.decay_ref_ms
        l = feats.get("low_ratio", 0.0) / self.low_ref
        c = self.crest_ref / max(feats.get("crest", 1e-6), 1e-6)
        z = 1.6 * (d - 1.0) + 1.4 * (l - 1.0) + 0.6 * (c - 1.0)
        return float(np.clip(self._sig(z), 0.0, 1.0))

class ModelClassifier:
    """Trained sklearn model. Falls back to RuleClassifier if the file is missing."""
    def __init__(self, path):
        import joblib
        self.model = joblib.load(path)

    def score(self, feats):
        v = to_vector(feats).reshape(1, -1)
        return float(self.model.predict_proba(v)[0, 1])

def load_classifier(cfg) -> Classifier:
    from pathlib import Path
    p = Path(cfg.classify.model_path)
    if p.exists():
        try:
            return ModelClassifier(p)
        except Exception as e:
            print(f"[classify] model load failed ({e}); using RuleClassifier")
    return RuleClassifier()

opoyo/veto.py
import csv, os
import numpy as np

class AcousticVeto:
    """YAMNet says what the room sounded like. Never raises — a broken veto
    must degrade to 'no veto', never to a crash that loses a real fall."""

    def __init__(self, classes, threshold=0.30):
        self.classes = set(classes)
        self.threshold = threshold
        self.ok = False
        try:
            import tensorflow_hub as hub
            self.model = hub.load("https://tfhub.dev/google/yamnet/1")
            path = self.model.class_map_path().numpy().decode()
            with open(path) as f:
                self.names = [r["display_name"] for r in csv.DictReader(f)]
            self.ok = True
        except Exception as e:
            print(f"[veto] disabled: {e}")

    def check(self, audio_16k) -> tuple[bool, str, float]:
        if not self.ok:
            return False, "", 0.0
        try:
            w = np.asarray(audio_16k, dtype=np.float32).ravel()
            if w.size < 16000:                       # pad to at least 1 s
                w = np.pad(w, (0, 16000 - w.size))
            w = np.clip(w, -1.0, 1.0)
            scores, _, _ = self.model(w)
            mean = scores.numpy().mean(axis=0)
            best_label, best_score = "", 0.0
            for i, s in enumerate(mean):
                if self.names[i] in self.classes and s > best_score:
                    best_label, best_score = self.names[i], float(s)
            return (best_score >= self.threshold), best_label, best_score
        except Exception as e:
            print(f"[veto] error, passing through: {e}")
            return False, "", 0.0

Troubleshooting

Check here before asking. Most of what goes wrong this week is on this list.

ModuleNotFoundError: No module named 'opoyo'

You're not in the repo root, or the venv isn't active. Every command runs from the directory containing config.yaml, with .venv active. Check with pwd and which python.

The trigger fires constantly, even in silence

Three usual causes, in order of likelihood: the high-pass filter state is being reset every chunk (P2.1 test 2 catches this); the baseline hasn't collected 5 samples yet so the threshold is inf and your min_peak_mag is doing all the work; or the phone is on a wobbly surface. Print the threshold each second and watch it.

Alerts arrive several seconds late

You're extracting features on the whole 30 s buffer instead of a 2 s window, or YAMNet is running on every chunk instead of only on triggers. The veto must run once per candidate event, never continuously.

Everything works on my machine but not the demo laptop

Different mic device index, different sample rate support, or the TF Hub cache is missing. Run pytest -q and the P4.1 offline check on the demo laptop specifically. Decide on Tuesday which physical laptop is the demo machine and stop switching.

Telegram works from curl but not from Python

.env isn't loaded, or the token has quotes around it. Print repr(secret("TELEGRAM_BOT_TOKEN")) — you should see a bare string with no quotes and no trailing newline.

pytest passes but the live system behaves differently

Almost always filter or trigger state that tests construct fresh and the live loop reuses. Replay a fixture through the live code path with scripts/replay.py rather than through the test doubles.
