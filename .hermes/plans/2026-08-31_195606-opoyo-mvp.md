# OPOYO MVP Implementation Plan

> **For Hermes:** Implement task-by-task. Do not reopen the phone-as-proxy decision. Do not train a 1D-CNN in this window.

**Goal:** Ship a live, demoable fall-detection MVP by Thursday 3 Sep 2026 21:00 SGT: iPhone on the floor streams accel + mic to a Mac dashboard, fusion decides fall vs dropped object, Telegram fires, README + demo video exist.

**Architecture:** The production node is a bonded piezo puck. This build is the proposal's own hackathon prototype: phone MEMS accel + mic as a dual-channel proxy, all inference on the Mac, only an event payload leaves the laptop. No cameras. No wearable. Detection is a deterministic fusion of a kinematic envelope gate and an acoustic veto, not a trained fall classifier. YAMNet is an optional veto if it loads; FFT centroid is the fallback so the demo never depends on TensorFlow.

**Tech Stack:** Python 3.11+, FastAPI, uvicorn, NumPy, SciPy, websockets. Phone client is a Safari page (DeviceMotion + getUserMedia). Dashboard is a static HTML page served by FastAPI. Telegram Bot API for t+0. Twilio is optional, behind an env flag. pytest for fusion tests only.

## Demo script the software must survive

1. Drop a metal object or slam a book: kinematic spike, acoustic veto, **no Telegram**.
2. Person drops to knees / controlled fall beside the phone: kinematic pass, no veto, **Telegram fires**, dashboard shows CONFIRMED FALL.

### Task 2: Fusion core with tests (no I/O)

**Objective:** A pure function that, given accel windows and an audio spectrum, returns `veto | candidate | confirmed` without touching the network.

**Files:**
- Create: `server/fusion.py`
- Create: `tests/test_fusion.py`

**Contract:**
```python
@dataclass
class FusionResult:
    state: str            # "idle" | "veto" | "candidate" | "confirmed"
    peak_g: float
    rise_ms: float
    decay_ms: float
    spectral_centroid_hz: float
    reason: str
```

Rules (defaults, overridable via env):
- Kinematic candidate if `peak_g >= FUSION_PEAK_G` AND `rise_ms >= FUSION_RISE_MS` AND `decay_ms >= FUSION_DECAY_MS`
- Acoustic veto if centroid `> 2500 Hz` (metallic / book slap). Human thud is low.
- Confirmed only if kinematic candidate AND not vetoed.
- Recovery: after candidate, if RMS accel exceeds walk threshold inside `RECOVERY_S`, mark near-miss.

**Step 1: Write failing tests** in `tests/test_fusion.py`:
- synthetic rigid impulse (fast rise, fast decay, high centroid) -> `veto`
- synthetic body envelope (slower rise, long decay, low centroid) -> `confirmed`
- below-threshold tap -> `idle`
- confirmed then footsteps -> near-miss / recovery

**Step 2:** `pytest tests/test_fusion.py -v` must fail (module missing).

**Step 3:** Implement `server/fusion.py` with NumPy only. No TensorFlow.

**Step 4:** `pytest tests/test_fusion.py -v` expected: 4 passed.

**Step 5:** Commit `feat: kinematic plus acoustic fusion heuristics`
